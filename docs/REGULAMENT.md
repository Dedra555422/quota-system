# РЕГЛАМЕНТ СИСТЕМЫ КВОТ ДЛЯ СОТРУДНИКОВ ПРОКУРАТУРЫ

## ОБЩИЕ ПОЛОЖЕНИЯ
1.1. Система квот вводится для контроля эффективности работы сотрудников прокуратуры.
1.2. Квота – это минимальное количество выполненных баллов за определённый период.
1.3. Учёт выполнения квоты ведётся сотрудниками Отдела Кадров
1.4 Вся работа связанная с работой баллами регулируется системой баллов и системы квоты

## НОРМЫ КВОТ ПО ДОЛЖНОСТЯМ
| Должность | Недельная квота |
|---------------------------|-----------------|
| Стажёр Военной Прокуратуры | освобождён |
| Помощник Военного Прокурора | 40 баллов |
| Старший Помощник Военного Прокурора | 40 баллов |
| Военный Прокурор  | 50 баллов |
| Старший Военный Прокурор | 50 баллов |
| Секретарь Военной Прокуратуры | 40 баллов |
| Заместитель Главного Военного Прокурора | 40 баллов |
| Сотрудник ОК+ | 30 баллов |

## ПОРЯДОК СДАЧИ ОТЧЁТА
2.1. В конце КАЖДОЙ недели сотрудник заходит в канал (название канала)


## УЧЁТ И КОНТРОЛЬ
4.1. Каждый сотрудник обязан писать в конце недели отчет о проделанной работе.
4.2. Еженедельно Суббота-воскресенье квота обнуляется 
4.3. Итоги квоты публикуется от ОК в конце недели
4.4. По всем вопросам касательно квоты нужно обращаться к непосредственному менеджеру ОК+

## ПООЩРЕНИЯ ЗА ПЕРЕВЫПОЛНЕНИЕ
5.1. За перевыполнение недельной квоты на 200% - приписывается вам к итогам квоты, подпись "Молодец!"
5.2. Лучший сотрудник получает роль «Ударник прокуратуры» 

| Нарушение | Санкция |
|-----------|---------|
| Невыполнение недельной квоты | Выговор |
| Второе невыполнение квоты подряд | Выговор|
| Третье невыполнение квоты подряд | Увольнение |
| Фальсификация отчётов | Строгий выговор |
| Обход/читерство и т.д. | Строгий выговор |

## ЗАКЛЮЧИТЕЛЬНЫЕ ПОЛОЖЕНИЯ
6.1. Регламент вступает в силу с момента публикации.
6.2. Изменения в регламент вносятся Кураторским составом Отдела Кадров, при одобрении Генеральной Прокуратуры
6.3. Все сотрудники обязаны ознакомиться с регламентом под сообщением (реакция ✅).
6.4. Игнорирование регламента = автоматическое согласие на штрафные санкции.
